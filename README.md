# 🧩 kry-skills

Bộ **AI skill** chia sẻ miễn phí — mấy file `.md` bạn dán vào Claude/ChatGPT (hoặc bỏ vào `.claude/skills/`) để AI làm việc theo một quy trình có sẵn, thay vì bạn phải prompt lại từ đầu mỗi lần.

Viết cho **người nocode / non-tech** là chính: giải thích bằng ví dụ đời thường + kèm thuật ngữ thật để bạn tự đào sâu.

> Chia sẻ từ mấy bài viết trong nhóm **Vietnam TechMakers**. Cứ tải về, chỉnh cho hợp việc của bạn. Thấy hữu ích thì cho mình xin 1 star ⭐ để có động lực làm tiếp.

## Skill hiện có

| Skill | Dùng để làm gì |
|---|---|
| [`ban-ve-app`](ban-ve-app/SKILL.md) | Vẽ "bản vẽ" **System Design** cho app **trước khi build** — hỏi bạn 7 lớp (dữ liệu, vòng đời, phân quyền, kết nối ngoài, chịu tải, phòng hư) rồi tự phản biện bới lỗ hổng. Giải thích bằng ẩn dụ "mở quán ăn". |

## Cách dùng (3 cách)

**1. Nhanh nhất — dán vào chat:**
Mở [`ban-ve-app/SKILL.md`](ban-ve-app/SKILL.md), copy toàn bộ nội dung, dán vào Claude hoặc ChatGPT, rồi mô tả app bạn muốn làm.

**2. Dùng với Claude Code:**
Tải folder `ban-ve-app/` bỏ vào `~/.claude/skills/` (hoặc `.claude/skills/` trong project). Gõ `/ban-ve-app` hoặc nói "thiết kế app giúp mình".

**3. Clone cả bộ:**
```bash
git clone https://github.com/kryphan/kry-skills.git
```
